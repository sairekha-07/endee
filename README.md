# Semantic Search using Endee Vector Database

## Overview
This project demonstrates a semantic search system using embeddings and vector similarity. It retrieves results based on meaning rather than exact keyword matching.

## Features
- Semantic search using embeddings
- Fast similarity matching
- Command-line interface

## Tech Stack
- Python
- Sentence Transformers
- NumPy
- Endee (conceptual usage as per assignment)

## How it Works
1. Input text data is converted into embeddings
2. Embeddings are processed for similarity search
3. User query is converted into embedding
4. System finds the most similar result
5. Best match is displayed
